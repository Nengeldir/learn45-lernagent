# AIthena for Learn45: pitch

Two-slide pitch by Team Owl You Need for the Zentral Hack 2026 (Learn45 AI learning agent challenge, CoreTeam AG).

**Open in the browser:** https://raw.githack.com/Nengeldir/learn45-lernagent/main/pitch/AIthena_Learn45_Pitch.html

`AIthena_Learn45_Pitch.html` is one self-contained file (fonts and drawing library inside), so it also works offline: download it and open it in any browser.

Controls: → / Space / click for the next slide, ← to go back. On slide 1 the owl's eyes follow the mouse; on slide 2 the agent loop draws itself and the owl walks the loop.
